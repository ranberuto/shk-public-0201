About Shinkiro

Shinkiro is a private, single-user productivity and personal treasury application designed solely for personal management of financial ledgers, budgeting records, encrypted notes, and local workspace tasks across personal desktop and mobile devices.

Shinkiro is not a commercial service, SaaS platform, or multi-tenant public application. It does not provide public registration, multi-user accounts, or third-party data collection. The software operates strictly in private, personal environments owned by its creator.

Google Drive API Integration

Shinkiro integrates with Google Drive API strictly to enable the owner to synchronize their own encrypted application backups and workspace files between authorized personal devices (desktop and mobile).

  • Dedicated Backup Folder: The application operates strictly within a single user-selected backup folder inside the owner's personal Google Drive.
  • Client-Side Encryption: All sensitive financial transactions, balance sheets, and notes are encrypted locally using AES-256 before transmission to Google Drive.
  • Direct Cloud Handshake: All communications occur directly between the user's personal client device and Google's official Drive API endpoints. No intermediate servers or third parties ever access tokens, encryption keys, or data.
