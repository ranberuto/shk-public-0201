Shinkiro Privacy Policy

Effective Date: November 6, 2026 | Application Type: Private Personal Software

1. Overview & Privacy Philosophy

This Privacy Policy describes how Shinkiro (including desktop and mobile companion applications) handles user data. Shinkiro is built as an individual personal productivity, budgeting, and financial ledger tool.

We do not collect, monetize, process, or sell any personal information. There are no external tracking servers, third-party analytics SDKs, advertising networks, or telemetry trackers embedded in Shinkiro.

2. Google User Data & OAuth Scopes

Shinkiro requests permission to access the user's personal Google Drive account via official Google OAuth 2.0 protocols. The requested OAuth scopes are:

  • https://www.googleapis.com/auth/drive (Full file access to manage the dedicated Shinkiro backup directory on the user's personal Google Drive).
  • https://www.googleapis.com/auth/drive.readonly (Read-only access for secondary follower devices synchronizing backup state).

How Google User Data is Handled:

  • Local-Only Storage: OAuth authorization tokens and refresh tokens are stored exclusively on the user's physical device in the operating system's native secure keystore (Windows DPAPI on PC and Android Keystore on mobile).
  • Client-Side Encryption: All database payloads and financial ledgers uploaded to Google Drive are encrypted locally using AES-256 before transmission. Google servers only store ciphertext.
  • No Intermediate Servers: Authentication and file uploads occur directly between the user's application instance and Google API endpoints. No tokens or user data are ever routed through any external proxy or developer server.

3. Google API Services User Data Policy Compliance

Shinkiro strictly complies with the Google API Services User Data Policy, including the Limited Use requirements:

Shinkiro's use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

In accordance with these requirements:

  • We do not transfer or share Google user data with any third parties.
  • We do not use Google user data for advertising, marketing, profiling, or behavioral tracking.
  • We do not use Google user data for training machine learning (ML) or artificial intelligence (AI) models.
  • Human beings cannot view or inspect user files or Google user data under any circumstances.

4. Data Retention, Control & Deletion

The user maintains 100% control over all data stored on their device and in Google Drive. You may delete your backups or the Shinkiro folder in Google Drive at any time through the standard Google Drive web interface.

To revoke Shinkiro's access to your Google Account at any time, visit your official Google Account Third-Party Access Management Page and remove Shinkiro.

5. Developer Contact

Because Shinkiro is a private personal software project, for questions regarding this privacy policy or application security, contact the developer directly at your registered Google Cloud developer support email.
