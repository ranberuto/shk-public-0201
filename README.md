# Shinkiro - Public Legal Documentation

This repository hosts the official public legal documentation (Application Home Page, Privacy Policy, and Terms of Service) for the **Shinkiro** private personal application.

## Hosted Pages
- `index.html` - Application Home Page
- `privacy-policy.html` - Privacy Policy (Google API Limited Use disclosure compliant)
- `terms-of-service.html` - Terms of Service

## Purpose
This repository contains **strictly static HTML legal documents** required for Google OAuth 2.0 verification and Google Cloud Console OAuth consent screen configuration. It contains **no application code, no credentials, no tokens, and no user data**.
